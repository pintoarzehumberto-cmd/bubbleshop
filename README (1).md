# 🫧 BubbleShop — Chicles Premium

Página web para venta de chicles en el SCIS. Hecha con HTML, CSS y JavaScript puro — sin dependencias externas (excepto Google Fonts y Chart.js por CDN).

---

## 🚀 Cómo subir a GitHub Pages (gratis)

### Paso 1 — Crea una cuenta en GitHub
Ve a [github.com](https://github.com) y regístrate si aún no tienes cuenta.

### Paso 2 — Crea un repositorio nuevo
1. Haz clic en **"New repository"**
2. Ponle el nombre: `bubbleshop`
3. Márcalo como **Public**
4. Haz clic en **"Create repository"**

### Paso 3 — Sube el archivo
1. En la página del repositorio, haz clic en **"Add file" → "Upload files"**
2. Arrastra el archivo `bubbleshop.html`
3. **MUY IMPORTANTE:** Renombra el archivo a `index.html` antes de subirlo (o después desde GitHub)
4. Haz clic en **"Commit changes"**

### Paso 4 — Activa GitHub Pages
1. Ve a **Settings** del repositorio
2. En el menú izquierdo, haz clic en **"Pages"**
3. En *Branch*, selecciona **`main`** y carpeta **`/ (root)`**
4. Haz clic en **Save**

### Paso 5 — ¡Listo! 🎉
En unos minutos tu sitio estará en:
```
https://TU_USUARIO.github.io/bubbleshop/
```
